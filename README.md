# 오셀로

8×8 판에서 두는 오셀로. 컴퓨터와 하거나, 온라인으로 다른 사람과 겨룰 수 있어요.

## 규칙
- 흑이 먼저 둡니다. 내 돌로 상대 돌을 가로·세로·대각선으로 끼우면 그 돌이 모두 뒤집혀요.
- 뒤집을 돌이 없는 자리에는 둘 수 없어요.
- 둘 곳이 없으면 자동으로 패스, 둘 다 둘 곳이 없으면 끝나고 돌이 더 많은 쪽이 이겨요.

## 기능
- 컴퓨터 대전: 쉬움 / 보통 / 어려움, 내 색 고르기, 무르기, 둘 수 있는 곳 표시
- 온라인: 빠른 대전, 방 만들기(4글자 코드·초대 링크), 기권, 재대결(색 교대)
- 차례당 45초 제한, 연결이 끊겨도 30초 안에 돌아오면 이어서 진행

## 실행
```bash
npm install
npm start        # http://localhost:3007
npm test
```

`PORT`, `TURN_MS`(차례 제한 ms) 환경변수로 바꿀 수 있어요.

## 구조
- `public/rules.js`: 규칙과 컴퓨터 (브라우저·서버 공용)
- `public/game.js`: 화면, 입력, 온라인 클라이언트
- `server.js`: 정적 파일 + WebSocket 방/매칭
